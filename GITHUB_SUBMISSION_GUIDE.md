# How to submit Thiranex Task 2

1. Review and run the notebook yourself, explain the results and verify Thiranex allows synthetic data.
2. Go to https://github.com/new and create a **Public** repository named `Thiranex-Task2-Predictive-Modeling`.
3. In the new repository, click **Add file → Upload files** (or **uploading an existing file**).
4. Upload the **contents** of this folder (not the ZIP alone), including `charts/` and the executed `.ipynb`, then **Commit changes**.
5. Open the notebook and chart files in GitHub and confirm they display properly.
6. Copy your repo URL, e.g. `https://github.com/YOUR-USERNAME/Thiranex-Task2-Predictive-Modeling`.
7. In Thiranex → Task 2 → Submit Work, paste the full repository URL and submit.
8. Confirm that the dashboard shows your submission. Approval and certificate issuance are up to Thiranex.

Your Task 2 deadline as supplied is **22 Oct 2026**.
